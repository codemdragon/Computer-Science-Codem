A2CS Admin Panel

Connect to your GitHub repository to read and edit db.json. Changes are committed straight to your repo.

Token needs Contents: Read and write permission on this repository.
How to create a fine-grained token
  1. Go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token, name it (e.g. A2CS Admin).
  3. Under Repository access choose Only select repositories and pick this repo.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Generate the token and copy it here. It is stored only in this browser.
